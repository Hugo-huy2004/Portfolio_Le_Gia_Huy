# Hugo Portfolio

Website portfolio tĩnh, độc lập với Hugo Studio và không dùng backend.

```sh
npm install
npm run dev
npm run build
```

Vercel build bằng `npm run build`, output là `dist`. Tên miền `portfolio.hugowishpax.studio` được nối ở Cloudflare bằng CNAME do Vercel cung cấp, để **DNS only**.
